# Internal Review Checklist

Reviewed: 2026-07-11

## Technical checks

- [x] Manuscript describes purpose, design, scope, and limitations.
- [x] Claims are tied to repository artifacts or clearly labelled as plans.
- [x] Comparative claims use the maintained landscape and API matrix.
- [x] Reproducibility commands are network-free by default.
- [x] Live validation is opt-in and credential-safe.
- [x] AI assistance disclosure is present.
- [x] No provider, DOI, peer-review, or adoption claim is fabricated.

## Human review required

- [ ] Author confirms title, affiliation, authorship, and contribution statement.
- [ ] Author verifies every reference and technical claim.
- [ ] Author chooses whether the contribution meets a selected venue's scope.
- [ ] Author approves any final manuscript, DOI archive, or submission.

This checklist is a readiness record, not peer review or submission approval.
