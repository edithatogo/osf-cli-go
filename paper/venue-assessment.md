# Venue Assessment

Reviewed: 2026-07-11

## Journal of Open Source Software

JOSS is a plausible future journal target because it evaluates both the
software and a short `paper.md`, with open review. Current blockers are
research-impact evidence, a longer public-development/adoption record, and
human confirmation that the project is more than a minor utility or thin API
client. Do not submit until those gates are resolved.

## Zenodo

Zenodo is the appropriate archival route for a selected GitHub release and DOI
record. Enable the GitHub integration, verify metadata from `CITATION.cff`,
select the exact release, inspect the generated record, and obtain human
approval before publishing. No DOI record is created by this track.

## arXiv and other preprint servers

Keep deferred. The manuscript needs human authorship and claim review, and the
appropriate category and venue policy must be confirmed before any upload.
Preparation is complete enough for review; submission is not authorized by
this track.

## Decision

Prepare the manuscript and reproducibility packet locally. Defer external
submission until human review, release-candidate gates, and venue selection
are explicitly approved.
