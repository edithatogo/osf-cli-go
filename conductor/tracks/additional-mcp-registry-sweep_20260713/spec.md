# Additional MCP registry sweep

## Overview

Maintain a current, evidence-backed submission matrix for additional MCP
registries and agent marketplaces.

## Requirements

- Assess MCP.so, mcpservers.org, MCPize, MCP Market, LobeHub, Cline, Docker MCP
  Catalog, PulseMCP, MCP Central, and newly credible alternatives.
- Record submission method, ownership/auth requirements, cost, review process,
  listing URL, and current status.
- Separate public submission from prepared materials, blocked access, and
  actual approval.

## Acceptance criteria

- Dated matrix with source URLs and exact next actions.
- High-value submissions have dedicated tracks; low-value or unverifiable
  directories are explicitly deprioritized.
- No credentials or synthetic usage claims are committed.
