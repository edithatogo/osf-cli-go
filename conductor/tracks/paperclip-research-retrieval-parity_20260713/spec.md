# Paperclip research retrieval parity

## Overview

Benchmark the archived Paperclip MCP server against OSF CLI Go and adopt
maintainable research-retrieval capabilities that improve OSF discovery.

## Requirements

- Compare multi-provider preprint discovery, full-text retrieval, URL/DOI
  resolution, provenance, transport, tests, and maintenance evidence.
- Implement beneficial OSF-specific gaps or record an explicit deferral,
  rejection, or linked follow-up issue.
- Preserve deterministic output, authentication redaction, bounded resource
  usage, and opt-in live validation.

## Acceptance criteria

- Dated source-backed comparison is committed.
- Every material gap is implemented, deferred, or rejected with rationale.
- Tests, documentation, and release metadata remain synchronized.

## Out of scope

- Reproducing archived provider integrations that do not improve OSF workflows.
- Claiming hosted-service availability from an archived repository.
