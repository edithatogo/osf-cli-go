# Registry and coding-agent submission scorecard

## Overview

Maximize the quality and completeness of OSF CLI Go submissions across coding
agent marketplaces and MCP registries without fabricating scores or approval.

## Requirements

- Apply the weighted scorecard in `docs/registry-scorecard.md` to every target.
- Cover OpenAI Codex/Cowork, Anthropic Claude/Cowork, GitHub Copilot, Cursor,
  Cline, LobeHub, Gemini, Qwen, official MCP Registry, Smithery, Glama,
  MCP.Directory, Docker MCP Catalog, MCP.so, mcpservers.org, MCPize, and
  verified future targets.
- Prepare provider-specific assets, install tests, tool metadata, security
  disclosures, screenshots/logos, and dated receipts.
- Keep prepared, submitted, approved, rejected, and blocked states distinct.

## Acceptance criteria

- Every target has a score, evidence links, next action, and blocker state.
- Applicable requirements reach 100% or an explicit provider-specific waiver is
  recorded.
- External approval is never inferred from local validation.
