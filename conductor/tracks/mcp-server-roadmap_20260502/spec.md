# MCP Server Roadmap

## Objective

Keep the project CLI-first while shaping reusable OSF core packages that can later power an MCP server.

## Acceptance Criteria

- No MCP server is built before the CLI contracts and OSF API client stabilize.
- Internal package boundaries are reviewed for future MCP suitability.
- A later MCP track can reuse OSF API, auth, output, and download components without rewriting the CLI.
