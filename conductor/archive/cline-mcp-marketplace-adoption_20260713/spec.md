# Cline MCP Marketplace adoption

## Overview

Prepare and submit the OSF MCP server to the official Cline MCP Marketplace.

## Requirements

- Provide a 400x400 PNG logo and a concise reason for addition.
- Validate installation from the README or an `llms-install.md` guide using
  Cline-compatible configuration.
- Submit through the marketplace issue template and record the exact receipt.
- Distinguish prepared, submitted, approved, and rejected states.

## Acceptance criteria

- Submission packet and local validation pass.
- Upstream issue URL and review state are recorded.
- No approval is claimed before the marketplace repository reflects it.
