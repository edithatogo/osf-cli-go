# Publish the OSF extension to the Gemini CLI gallery

## Overview

Deliver Gemini extension validation, gallery metadata, submission, installation evidence, and provider review. Tracking issue: [#23](https://github.com/edithatogo/osf-cli-go/issues/23).

## Requirements

- Verify current requirements from authoritative sources and preserve dated links.
- Define measurable repository-local readiness and external provider gates.
- Produce tested, versioned, reproducible artifacts and validation evidence.
- Preserve credential safety, provenance, licensing, stable interfaces, and conservative writes.
- Record every submission, review response, rejection, approval, and remaining blocker.

## Acceptance Criteria

- All local checks and track review gates pass.
- Required artifacts install or validate on supported platforms.
- External submissions have durable evidence and are never marked published before approval is visible.
- Documentation distinguishes available, submitted, under review, approved, and blocked states.
- Remaining work is represented by linked issues rather than implicit TODOs.

## Out of Scope

- Claiming provider approval before it occurs.
- Sending a preprint or other publication without explicit final approval.
- Weakening security or compatibility to satisfy a directory score.
