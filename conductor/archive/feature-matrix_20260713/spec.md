# Comprehensive feature matrix

## Overview

Create a maintained, source-backed matrix that covers all CLI, API, MCP,
packaging, release, parity, and registry capabilities.

## Requirements

- Map each capability to code, tests, documentation, and a status.
- Include read/write safety, auth, output, pagination, platform, and external
  distribution dimensions.
- Link every gap to an existing or new Conductor track and issue.
- Update the matrix on every release and during each parity review.

## Acceptance criteria

- `docs/feature-matrix.md` is comprehensive and dated.
- No feature is described as complete without validation evidence.
- Matrix drift is detectable by review and release checks.
