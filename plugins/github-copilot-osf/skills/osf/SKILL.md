# OSF MCP Tools

Use the `osf` MCP server for Open Science Framework project, component, file,
contributor, registration, preprint, search, and export workflows.

Prefer `OSF_TOKEN` for authentication. Public read operations may run without a
token. Never print credentials, and require explicit user intent before write
or destructive operations.

Use stable JSON output for automation and preserve OSF identifiers and source
URLs in results.
